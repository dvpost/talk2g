# talk2g

Локальная русская диктовка на **GigaAM v3** для Linux и Windows.
Распознанный текст вводится в выбранное приложение целыми блоками после паузы.
После загрузки весов интернет и аккаунт Сбера для диктовки не нужны.

## Быстрый старт

На Linux:

```bash
git clone https://github.com/dvpost/talk2g.git
cd talk2g
./run-linux.sh
```

Первый запуск устанавливает окружение и скачивает веса. На Windows откройте
`run-windows.cmd`. Системные зависимости Linux, разрешения микрофона Windows
и авторизация Wayland описаны в [руководстве установки](docs/USAGE.md#установка-на-другую-машину).

В автономной поставке запускайте `talk2g` на Linux или `talk2g.exe` на Windows.
Переносите папку целиком; Python и uv для неё не нужны.
[Сборка и требования поставки](docs/VALIDATION.md#сборка-и-измерения).

## Диктовка

Поставьте курсор в нужное поле и нажмите **Ctrl+Shift+A**. После **3 секунд
без речи** накопленный блок распознаётся и вводится целиком. Новая речь
сбрасывает ожидание. Повторное нажатие завершает запись и сразу отправляет
оставшийся блок.

По умолчанию запись завершается после **45 секунд без речи**. Синее окно
находится справа сверху; жёлтая часть полоски показывает ожидание распознавания,
синяя — время до завершения сессии. Тайм-аут, пауза и положение окна меняются
в настройках.

Настройки и меню трея позволяют включать автоматический ввод, копирование,
аудиоархив, голосовую остановку «конец связи», автозапуск и загрузку модели
только на время диктовки. Текст сохраняется в истории; главное окно можно
закрыть в трей. «Выход» завершает приложение и запущенный им сервер.

[Подробное руководство](docs/USAGE.md) описывает настройки, архив записей
и поведение при смене окна. [Сервер и диагностика](docs/OPERATIONS.md)
содержит настройку удалённого подключения, профилей и журналов.
